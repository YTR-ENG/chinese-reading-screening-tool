# 中文阅读困难风险筛查工具

一个可以拷进 U 盘、双击就能打开、不联网也不安装的网页工具，帮助小学老师在约 10 分钟内完成一个班的阅读困难初步筛查，并自动生成每个孩子的风险等级、分项评价与针对性建议。

作者：闫庭睿 · iflab

---

## 它解决什么问题

发展性阅读障碍在学龄儿童中的发生率约为 5%~10%，但国内真正被识别出来的比例远低于这一水平，大量孩子长期被理解为"不努力""粗心"。

问题出在筛查环节：专业评估需要一对一施测 20~40 分钟，还要经过培训的主试，无法在学校规模上铺开。结果是"该测的人测不到"。

这个工具把筛查部分压缩成 30 道题、约 10 分钟，学生自己就能完成。老师拿到的是"哪些孩子建议进一步专业评估"的提示，而不是诊断结论。

## 功能

- **四个版块**：形近字辨别、字音匹配、短时阅读理解、短时记忆测试
- **题库 500 题**：形近字 300 题、字音 100 题、阅读 50 题、记忆 50 题
- **随机组卷**：每版块随机抽 10 / 8 / 6 / 6 题，选项顺序随机，同一人多次测试题目不同
- **记忆题计时**：材料页 10 秒倒计时，到时自动跳转答题页，两页相互独立
- **自动报告**：总得分、风险等级、各版块正确率与评价（良好 / 需关注 / 薄弱）
- **分项建议**：按各版块得分给出针对性的练习建议
- **离线运行**：单个 HTML 文件，不联网、不安装、不需要账号
- **隐私友好**：所有作答只保存在本机浏览器，不上传任何数据
- **可导出**：报告支持打印或保存为 PDF

## 使用方法

下载 `index.html`，双击用浏览器打开即可开始。

也可以通过 GitHub Pages 在线打开：

```
https://<你的用户名>.github.io/chinese-reading-screening-tool/
```

开始页上有一个"演示模式"链接，可以跳过答题直接查看报告样例。

## 技术说明

整个工具是一个自包含的 HTML 文件（约 39 KB），CSS、JavaScript 与题库全部内嵌，没有任何外部依赖：没有 CDN、没有接口调用、没有网络请求。原生 JavaScript 编写，不需要构建步骤，也不依赖任何框架。

题库在代码中以紧凑的文本格式存储，运行时生成完整题目：

- 形近字辨别由 150 组形近字生成两个方向的题目，共 300 题；干扰项取自一个与所有形近字组部件都不重叠的字池，保证每题只有一个"最接近"的正确答案。
- 字音匹配 = 60 题看字选音 + 40 题选同音字。
- 抽题时会避免同一组形近字、同一题干字在同一局内重复出现。

## 已知局限

这一节我们认为必须写清楚，而不是留到被问到才说：

- **没有常模**：风险等级阈值目前基于经验设定，尚未用真实儿童样本校准。
- **未做效度验证**：尚未与标准化量表做对照，敏感度与特异度未知。
- **答案在前端可见**：查看网页源码即可看到正确答案。因此本工具只适用于自测与教学演示，不适用于任何有利益影响的场景。
- **题库尚待专家审校**：个别字音题涉及多音字，需要小学语文教研员逐题复核。

下一步计划是到合作学校采集 60~100 名儿童的数据，建立初步常模区间并完成效度验证。

## 声明

本工具仅用于阅读困难的风险筛查预警，**不具备医学诊断效力**，结果仅供参考，不能替代医院或专业机构的评估。

各版块题量较少（6~10 题），单项结果不构成结论，只用于提示需要关注的方向。
